# DILSTM
本项目是《Multi-Modal Trajectory Similarity Learning with Differentiable Map Matching》论文的实验代码，实现了对轨迹在道路网络的软匹配相似度高效计算。
This project is the experimental code of the paper 《multi modal trajectory simulation learning with differential map matching》, which realizes the efficient calculation of soft matching similarity of trajectory in road network.
